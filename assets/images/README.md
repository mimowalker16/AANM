# Logo Setup Instructions

## Required Action

Please save your logo image as:
- **File name:** `logo.png`
- **Location:** This folder (`assets/images/`)
- **Recommended dimensions:** At least 400px wide for optimal display

## Where the logo is used

The logo will appear in:
1. **Navbar** - Top navigation bar on all pages (with white filter on transparent backgrounds)
2. **Footer** - Bottom of all pages
3. **Favicon** - Browser tab icon
